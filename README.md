# Танцы — учёт оплат 💃

Веб-приложение для iPhone: ученицы, абонементы, оплаты, отмены занятий.
Работает без интернета, ставится на экран «Домой» как обычное приложение.

## Как считаются оплаты

- **Абонемент** = N занятий (по умолчанию 8 ≈ месяц при Пн/Ср). Цена и число занятий настраиваются у группы.
- **Пропуск ученицы** — занятие списывается.
- **Отмена тренером** — занятие не списывается ни у кого, абонементы сами продлеваются.
- **«Уважительная»** отметка в посещении или **пауза** — не списывается только у этой ученицы.
- **Перенос** — «Перенос / отмена»: можно поменять только время в тот же день или перенести на другой день с новым временем.
- **Смена расписания** (например, с Пн/Ср на Вт/Чт) — в настройках группы, с выбранной даты; прошлое не меняется.
- **Своё время для каждого дня**: например, Пн 18:00 и Ср 19:00 — задаётся в группе.
- **Несколько групп** (например, дети в 17:00, сразу после взрослые в 18:30): у каждой свои дни, время,
  цена и ученицы. В один день занятия показываются по порядку времени, отменить можно каждое отдельно.
- **Дети**: у ученицы можно включить пометку «Ребёнок» — рядом с именем появится метка.
- Занятие списывается только **с момента его начала**: утром вечернее занятие ещё не списано.
- Оплаты покрывают занятия по порядку: сначала долги, потом будущие.

## Уведомления

Колокольчик на главной собирает всё сам, настраивать ничего не нужно: кто сегодня платит,
долги, занятие сегодня, отмены на завтра, дни рождения, окончание паузы, напоминание о копии.

## Где хранятся данные

Только на телефоне, внутри приложения (localStorage). На сервер ничего не отправляется,
поэтому сайт может открыть кто угодно — но увидит пустое приложение, а не ваши данные.

Данные могут пропасть, если: удалить иконку с экрана «Домой», очистить данные сайтов в настройках Safari,
сменить телефон без копии или изменить адрес сайта (переименовать репозиторий).
В Safari (не с иконки) у приложения отдельное пустое хранилище.

Раз в 1–2 недели: **Настройки → Сохранить копию** (в Файлы / Telegram «Избранное»).
Восстановление: **Настройки → Восстановить из копии**.

## Публикация на GitHub Pages (бесплатно)

1. Зарегистрироваться на https://github.com.
2. Создать репозиторий: **New repository** → имя, например `tancy` → **Public** → Create.
3. **Add file → Upload files** → перетащить всё содержимое этой папки
   (`index.html`, `manifest.webmanifest`, `sw.js`, папки `css`, `js`, `icons`) → **Commit changes**.
4. **Settings → Pages** → Source: *Deploy from a branch* → Branch: `main`, папка `/ (root)` → Save.
5. Через 1–2 минуты сайт будет по адресу `https://ИМЯ.github.io/tancy/`.

Или из терминала (если репозиторий уже создан на GitHub):

```bash
git init && git add . && git commit -m "Первая версия" && git branch -M main
git remote add origin https://github.com/ИМЯ/tancy.git && git push -u origin main
```

## Установка на iPhone

1. Открыть адрес сайта в **Safari** (именно Safari).
2. **Поделиться** → **На экран «Домой»** → **Добавить**.
3. Открывать с иконки «Танцы».

## Обновление приложения

После изменения файлов увеличьте `VERSION` в `sw.js` (например `v1.0.1`) и загрузите файлы заново.
Телефон скачает обновление при следующем запуске и предложит перезапустить приложение.

## Локальный запуск

```bash
python3 -m http.server 8765
```

и открыть http://localhost:8765
